Visualizing Gradient Descent & Regression Without Black Boxes

AI Sim Lab is an interactive, browser-based machine learning simulation engine. It allows students and evaluators to visually explore closed-form Normal Equation solvers versus iterative Gradient Descent, tune hyperparameter convergence rates, analyze overfitting across polynomial degrees, and process custom CSV datasets—all running locally with zero latency.

Architecture & Capabilities Overview

Modular structure supporting linear algebra, statistical metrics, and live rendering

Regression Engine

Supports Linear, Polynomial (Degree 1–6), and Exponential fitting algorithms. Toggles between closed-form solutions (`math.lusolve`) and iterative Gradient Descent.

Interactive Canvas

Direct plot interaction allows users to add or remove data points on click. Re-calculates Mean Squared Error (MSE), $R^2$ fit scores, and residual bars live.

CSV Data Processing

Integrated PapaParse parser to load external dataset files or paste raw CSV text with automatic column detection and validation.

Perceptron Lab (Bonus)

Single-layer perceptron playground for 2D binary classification. Demonstrates real-time weight ($w_1, w_2$) and bias updates while rotating the boundary.
